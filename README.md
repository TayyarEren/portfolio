# Portfolio · Tayyar Eren

Persönliche Website über meinen beruflichen Hintergrund, technische Themen und Projekte. Die Seite verbindet IT, Betriebswirtschaft und praktische Berufserfahrung.

## Start

1. Repository über **Code → Download ZIP** herunterladen und entpacken.
2. `index.html` in einem aktuellen Browser öffnen.

HTML, CSS und JavaScript liegen gemeinsam in einer Datei. Ein Build-Schritt ist nicht erforderlich.

## Dateien

| Datei | Bedeutung |
| --- | --- |
| `index.html` | Einstieg in die Portfolio-Website |
| `index` | Weitere vorhandene Portfolio-Fassung ohne Dateiendung |

## Funktionen

- Deutsch und Englisch
- Helles und dunkles Farbschema
- Bereiche für Werdegang, Kompetenzen, Projekte und Kontakt
- Layout für unterschiedliche Bildschirmgrößen

## Stand und Varianten

Die Datei `index.html` ist beim Vergleich vom 03.10.2026 inhaltlich identisch mit den Dateien in [Portfolio-Eren](https://github.com/TayyarEren/Portfolio-Eren) und [tayyar-CV_1](https://github.com/TayyarEren/tayyar-CV_1).
Dieses Repository dient als zentraler Einstieg für die Portfolio-Varianten.

**Offene Punkte:** Die eingebundene Bilddatei `Bilder/tayyarerenPortfolio.png` fehlt im Repository. Einige berufliche Statusangaben stammen aus der Umschulungs-/Praktikumszeit und sollten vor einer weiteren Verwendung aktualisiert werden.
